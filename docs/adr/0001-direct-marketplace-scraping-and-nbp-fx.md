# Direct Marketplace Scraping with NBP FX Normalization and Interactive Override

We resolve product availability, `ItemPrice`, and `ShippingQuote` by fetching Amazon product (`/dp/{ASIN}`) and search (`/s?k=`) pages directly from backend Node.js HTTP workers across 9 European marketplaces (`PL`, `DE`, `ES`, `IT`, `FR`, `NL`, `SE`, `BE`, `UK`), combined with official `EUR`, `GBP`, and `SEK` exchange rates from Narodowy Bank Polski (`api.nbp.pl`), rather than requiring commercial third-party APIs (Keepa, Rainforest). Because Amazon storefronts intermittently enforce bot protection (CAPTCHA / HTTP 503) or hide cross-border shipping to Poland unless an authenticated address session is present, our parser extracts delivery quotes from multiple DOM locations (`#mir-layout-DELIVERY_BLOCK`, `data-csa-c-delivery-price`, `#priceBadging_feature_div`), accepts optional user-provided session cookies/postal codes (`DeliverySessionConfig`), and pairs every row in the UI with instant manual price/shipping overrides so a blocked or login-gated storefront never breaks the comparison workflow.
